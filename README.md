# SISTEC - Sistema de Chamados (Versão Desktop)

## O que precisa para rodar?


1. `Servidor Aberto`  
   Abrir o servidor em [sistecPrograms](https://github.com/lucasleandro08/sistecPrograms){target="_blank"} com o comando:
   ```bash
   npm run dev
   ```

2. `Visual Studio`  
   Ter o Visual Studio instalado

3. `C#`  
   Ter o C# 7.8 ou superior instalado

4. `.NET Framework`  
   Ter o .NET Framework 4.8 ou superior instalado
